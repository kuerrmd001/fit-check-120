# Project Memory

## Core
Fit Check should follow an iOS-inspired, mobile-first Thai health app style.
Use bright white surfaces, deep navy text, and teal/green as the primary action color.
Keep the tone calm, supportive, and safety-first; never present the app as a diagnosis tool.
Reference uploads are for visual direction only, not direct embedded assets.
